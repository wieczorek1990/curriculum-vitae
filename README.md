# Curriculum Vitae

## Installation
Download PKG from TUG:
* [BasicTeX](https://www.tug.org/mactex/morepackages.html)
* [MacTeX](https://www.tug.org/mactex/)

### Dependencies
* BasicTeX with the following:
```sh
git clone git@github.com:wieczorek1990/curriculum-vitae.git
cd curriculum-vitae/
./bin/install.sh
````
* With MacTex you do not have to install library files.
